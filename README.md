# NBA-Winning-Analysis
An exploration of data science and learning taken from reading the ISLP textbook
Used HTML scraping to find money spread data from ESPN, along with using the basic ESPN api to call historical team data.
Tabled winning odds from Kalshi before tip off of games and recorded the outcomes of said games.
If I were to return to this I would pay for the data of prediction markets before the tip off of games to find out
if there was a gap between the probabilistic outcome of a game and the probability of what people thought the outcome of the game 
was going to be before tipoff.
